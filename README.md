# Fake Job/Internship Scam Detector

A Python tool that analyzes job postings for common scam red flags, built after noticing templated/suspicious listings during my own internship search.

## What it checks
- Requests for upfront payment (major red flag)
- Missing company website
- Unusually low stipend
- Suspiciously short job descriptions

## Example output
